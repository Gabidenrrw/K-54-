# Переводы

Отдельный Flutter-макет по предоставленной фотографии. Не выполняет банковские операции. На результате и в квитанции постоянно отображается «ПЛАТЁЖ НЕ ВЫПОЛНЯЛСЯ», в квитанции также «НЕ ПОДТВЕРЖДАЕТ ОПЛАТУ». Слова «Демо» и «Макет» в интерфейсе не используются.

Приложение начинается с формы «Клиенту Kaspi»: карта списания, вкладки, получатель, сумма, сообщение и подсказки. По умолчанию открыта вкладка «Телефон», поле начинается с `+7`, автоматически форматируется как `+7 701 123 45 67` и принимает вставку номера через `8` или `+7`. До полного совпадения с локальной базой имя и жёлтая плашка скрыты. Для неизвестного номера переход к результату заблокирован.

Значок настроек или карта списания → «База получателей»: добавление и редактирование телефона, имени, необязательной карты и собственного фото. «Загрузить фото» открывает системный выбор изображения; доступны замена и удаление фото из записи. Выбранное изображение проверяется и копируется в приватную постоянную папку приложения; записи сохраняются локально в отдельном JSON-ключе SharedPreferences. Старые записи без нового поля совместимы. Дубликаты телефона и карты отклоняются. Полный номер выбирает имя и фото из базы; карта работает аналогично, если её добавили в запись. Сумма обновляет нижнюю кнопку; результат и квитанция получают выбранное имя, квитанция также отображает выбранное фото. При отсутствии фото аватар полностью скрыт. В настройках отдельно меняются отправитель и баланс.

Вкладка «Kaspi QR» открывает настоящую камеру с запросом разрешения. Камера заполняет фон, сверху — заголовок и крестик, рамка состоит из оранжевых углов, ниже — фонарик и карточка «Онлайн рәсімдеу». Любой считанный QR показывает «QR-код не распознан», повторные кадры объединяются в один диалог. Содержимое не открывается и не используется для подстановки данных. Камера приостанавливается при уходе из приложения и закрывается при выходе из сканера. Отказ в разрешении показывает понятное сообщение и кнопку повтора. Значок ввода карты сохраняет прежний ручной ввод. Банковские интеграции не подключены.

Карандаш на экране результата открывает прежнюю форму имени и суммы. «Вернуться в Переводы» возвращает на начальный экран. Данные и переключатель «Частые» сохраняются локально между запусками. Сумма хранится в целых тиынах, без вычислений с плавающей точкой. Прежний виджет `MainApp` сохранён с исходным поведением; новый начальный маршрут реализован отдельным `TransferEntryApp`.

«Показать квитанцию» открывает отдельный экран с фигурными краями бумаги и нижними действиями. Отправитель вводится в форме или по нажатию на строку «Отправитель». Видимый тестовый номер имеет префикс `ТЕСТ-` и 18 случайных цифр; создаётся при открытии квитанции или изменении данных и не меняется при перерисовке. Дата отображается по Астане (UTC+5). «Поделиться» открывает системное меню с пометкой «ПЛАТЁЖ НЕ ВЫПОЛНЯЛСЯ — НЕ ПОДТВЕРЖДАЕТ ОПЛАТУ»; «Повторить перевод» возвращает форму, «Запросить отмену» сообщает об отсутствии платежа, «Частые» сохраняются локально. Старые методы модели и прежний формат данных сохранены для обратной совместимости; для отображения добавлены новые свойства.

Roboto включён в APK; для начального маршрута добавлены статические начертания 450/500/600/700, основной текст немного плотнее прежнего Regular. QR-значок с рамкой нарисован в SVG по фотографии. Интернет для отображения не нужен. Реклама статична: Flutter отображает соответствующие области исходной фотографии, без изменения файла.

Проверено с Flutter 3.44.2 / Dart 3.12.2. Установлены Gradle 9.4.1, Android Gradle Plugin 9.2.1 и Kotlin 2.3.21.

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug --target-platform android-arm64
flutter run --debug -d 10AFCZ2C00005L6
```

Исходные материалы: [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto), [Google Material Icons](https://github.com/google/material-design-icons). Квитанция нарисована в SVG по фотографии. Лицензии включены рядом с ассетами. Фотографии предоставлены пользователем; общий аватар из исходной фотографии больше не отображается. Логотип адаптирован из локального SVG EvnShell. EvnShell был просмотрен только для справки; его код и интеграции не изменялись. Камера: [mobile_scanner](https://pub.dev/packages/mobile_scanner), выбор изображения: [image_picker](https://pub.dev/packages/image_picker), локальная папка: [path_provider](https://pub.dev/packages/path_provider).
